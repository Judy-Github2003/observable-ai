# 研究提案记录

> 状态：提案不等于授权。当前仅 E3-A 获准；E3-B/C 未授权，不得自动实施。
> 每条提案标注：动机、最小可验证方案、可能反例、优先级。

## P1 — 进程级评测隔离（建议优先）

**动机**：当前同 JVM 仅接口隔离；worldId 哈希低熵可枚举，生成器/seed/HiddenTruth 与学生同环境。A5/A7 的“受控网关”仍是代码约定。

**最小方案**：评测进程生成世界、持有 seed/oracle；学生进程只收 `StudentView` JSON，通过进程边界请求 query；所有请求/响应带 nonce 和审计 ID。正式考试不把 evaluator 包放入学生 classpath。

**反例**：若学生只靠查询模式推断 family，说明 gateway 允许的查询集合本身泄漏；需匹配查询池。

**优先级**：高（A9 之前或同时）。

## P2 — A9 公平对照协议（当前阶段建议）

**动机**：避免 A8 因规则更多/预算更大而“赢”，而不是因为诊断增量。

**最小方案**：
- 预注册世界、seed、样本数、排列、预算、查询成本；
- 基线 A4/A5/A6/A7/A8 同输入；
- 主指标 false-certainty（错误声称 identified/noise/representation gap）；
- 次指标 abstention、hidden prediction、info gain/cost、trace completeness；
- 匹配世界：同公开观察、不同隐藏真值；
- 盲评由独立脚本从原始 run-results 计算。

**反例**：A8 只在冲突多、易识别的世界赢；匹配世界不赢则无增量价值。

**优先级**：高（A9 直接执行）。

## P3 — 表示不足判定协议（E3-B/C 前置）

**动机**：当前 `SEARCH_TRUNCATED` 不能证明表示不足；`noConsistent` 也可能只是预算/查询域不足。

**最小方案**：只有同时满足才可报告 `REPRESENTATION_GAP`：
1. 固定 IR/预算的覆盖/穷尽证明；
2. 新增一个**新观察通道**（非现有字段新取值）后仍不可分；
3. 明确 identifiability 论证与替代解释。

否则只报 `UNDETERMINED_WITHIN_CURRENT_VOCABULARY`。

**反例**：更宽预算找到候选，则原先“表示不足”说法被推翻。

**优先级**：高（在 E3-B 开始前冻结）。

## P4 — 传感器成本/可靠性/覆盖模型（E3-B）

**动机**：A7 的查询是零成本/单步/无可靠性；真实主动学习需要成本与噪声。

**最小方案**：每个公开传感器有 cost、latency、coverage、reliability 声明；策略最大化 expected information gain per cost，允许 NoAction；可靠性冲突单独记录，不默认可信。

**反例**：最便宜传感器信息增益低但足够；纯成本贪心可能不如随机。

**优先级**：中高。

## P5 — 有类型约束的表示构造（E3-C）

**动机**：开放 AST 搜索会组合爆炸且不可验证；当前 IR 仅 Bool3 规则。

**最小方案**：新谓词/关系模板有类型、参数域、复杂度预算；晋升需 held-out 验证 + 压缩收益 + 至少一个跨任务迁移；版本化、可撤销。

**反例**：只在训练世界压缩、跨世界无效，则不得晋升。

**优先级**：中（需 P3 先定标准）。

## P6 — 校准与“证据强度”指标

**动机**：A8 findings 是硬编码规则，没有置信度/证据强度；容易过度报告。

**最小方案**：为 finding 记录证据计数、来源独立性、冲突比例、预算覆盖率；评测 reliability diagram / Brier / false-certainty，而非只报准确率。

**反例**：校准好但信息增益低，说明策略保守；需同时报告覆盖。

**优先级**：中。

## 我对路线的主要不同意见

- 不建议把 E3-B 做成“在现有字段里选更多值”；那不能解决完全别名冲突，也无法支撑表示演化。
- 不建议把 E3-C 做成“更大 AST 搜索”；应先有 P3 的不可辨识协议和 P5 的验证/迁移标准。
- 不建议用单一准确率作为 A9 主指标；false-certainty 与正确弃权更贴近研究目标。
