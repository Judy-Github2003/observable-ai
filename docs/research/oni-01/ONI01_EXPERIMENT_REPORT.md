# ONI-01 实验结果

执行与报告：Codex，2026-11-17～18。独立考官和产物核对由同机独立 Codex 子代理承担。状态：实验结束，提交负责人审查；研究目标未全面通过。

## 1. 结论

**P0 前向链路成立；P1～P4 未通过正式隐藏测试。** 在第 27 号 decoder block 后注入真实 BF16 hidden state，下一层确实消费修改后的向量，后续 14 层和原始 LM head 的 logits 均变化。但强制注入在两个新世界的适用题上仍只有 **2/12**，与 BASE 相同，beneficial flips 为 **0**。激活门控 **0/12** 召回，当前版本不具备可用的跨世界自动触发能力。

这轮证明了可观测、可干预的计算通道，尚未证明可靠的显式知识注入能力。没有修改基础权重，没有把上述工程结果记作模型自身学会规则。

## 3. A–F 与恢复结果

准确率按单个完整短答案判定，大小写不敏感，允许末尾标点。歧义单列，不混入适用题。表中收益/损害/输出变化均指12道 HELDOUT、相对于 BASE。

|---|---:|---:|---:|---:|---:|---:|---:|
| A BASE | 2/12 | 4/8 | 0/4 | 4/4 | 0 / 0 | 0/12 | 0/12 |
| B SHAM | 2/12 | 5/8 | 0/4 | 4/4 | 0 / 0 | 2/12 | 12/12 |
| C FORCED | 2/12 | 4/8 | 0/4 | 4/4 | 0 / 0 | 2/12 | 12/12 |
| D GATED | 2/12 | 4/8 | 0/4 | 4/4 | 0 / 0 | 0/12 | 0/12 |
| E ABLATE | 2/12 | 4/8 | 0/4 | 4/4 | 0 / 0 | 0/12 | 0/12 |
| F WRONG | 2/12 | 3/8 | 0/4 | 4/4 | 0 / 0 | 3/12 | 12/12 |
| RECOVERY | 2/12 | 4/8 | 0/4 | 4/4 | 0 / 0 | 0/12 | 0/12 |

两个新世界各6道 HELDOUT，所有条件均各答对1道。普通控制4/4的保持不能弥补目标能力没有收益；GENERAL 无可解析 capsule，实际没有注入，不能据此证明“对所有无关任务都不会造成干扰”。

NEGATIVE 的 FORCED 总分相同，但发生一次收益与一次损害；SHAM 有一次收益，WRONG 有一次损害，见完整评分和失败明细。这些不是语义目标能力提升。AMBIGUOUS 所有条件均0/4，失败保留。

例如适用题q11af59b06a真值saffron：BASE输出UNKNOWN，FORCED与WRONG均输出`vektor saffron`，仍不满足预定单值输出；qac0672356f真值pear：FORCED输出UNCOVERED。阴性qbc80dc87bb由linvar改为UNKNOWN，qc9277aa51e则由UNKNOWN改为`vektor bronze`，一正一负抵消。未在揭盲后放宽判分。全部196条中126条未答对：83条错误UNKNOWN、29条其他错误短答、14条格式不合；原始输出全部保留。

## 4. 前向路径与对照证据

FORCED 的12道适用题全部有有限、非零 BF16 delta，下一层输入与修改后向量逐元素相等。实际 delta/原hidden范数为 **0.1912～0.2301**；第28层相对BASE向量差范数 **9.633～11.900**，第41层 **21.062～29.633**，首步logits最大绝对差 **1.539～3.445**。首步真实张量及关键下游向量存于 activation trace；每题七条件全词表首步 BF16 logits 独立保存。

SHAM 和 WRONG 使用同位置、相近的请求增量范数；BF16舍入后SHAM实际delta/hidden为0.1912～0.2299，WRONG为0.1912～0.2298。它们也改变下游，说明仅凭“激活变了”无法声称特定知识有效。

28/28题 **BASE=ABLATE**：完整首步logits及原始生成逐元素/逐字一致。28/28题 GATED=RECOVERY，也与BASE一致。消融链路正确，但本轮没有可消失的隐藏集行为收益。

**恢复控制存在设计缺口：** FORCED/WRONG固定gate=1，RECOVERY使用激活门控。隐藏集门控全部关闭，因此RECOVERY没有恢复强制注入，FORCED与RECOVERY仅6/28题logits一致，不能冒充同门控恢复实验。开发集成本补测中，dev01可复现 BASE/SHAM/ABLATE/WRONG=`UNKNOWN`，FORCED/GATED/RECOVERY=`blue`；这只是已见正控制，不能提升隐藏集验收等级。

`next_consumed` 和逐层原始trace来自独立诊断prefill；正常生成期间hook持续启用并记录调用次数，每步重复改写原prompt末token。尚未保存生成每一步的消费trace，未测试KV cache。

## 5. 门控与目标概率

门控只读查询位置激活和文本位置锚点，不读领域标签、规则结果或考官类别。DEV上 TP/FP/TN/FN=10/0/7/0；隐藏集 **0/0/16/12**，precision未定义（无阳性预测），recall=0，FPR=0。排除歧义后为0/0/12/12。低FPR来自全部拒绝，不能称可靠门控。12道适用题gate score范围0.1703～0.2167，全低于冻结阈值。

考官离线以真实目标首token计算 `float32(logits).log_softmax()[tokenizer.encode(target)[0]]`，未把标签传回模型。HELDOUT相对BASE的log-prob变化中位数：SHAM +0.3369、FORCED +0.4654、WRONG −0.0696、GATED/ABLATE/RECOVERY 0。FORCED范围 −1.5286～+3.2962。首token概率局部改善没有变为完整答案收益，不能代替准确率。28题中20个目标是多token，空格版本敏感性另存考官明细。

## 6. 成本与验证

正式HELDOUT仅生成阶段时延p50：BASE215.0ms、SHAM230.1ms、FORCED239.1ms；GPU峰值约5.06GB（十进制，生成阶段）。原始字段不包含解析、动态码本和额外诊断forward，不能标成端到端。

另对预先指定的DEV01、DEV04、DEV09、普通算术控制各跑一次七条件，从请求解析/锚点采集到原始生成及CPU统计，暖模型端到端p50：BASE188.0ms、SHAM288.8ms、FORCED240.1ms、GATED248.6ms、ABLATE285.3ms、WRONG282.5ms、RECOVERY239.1ms。注入条件锚点本身p50约98～100ms；BASE省略锚点。该补测仅4个开发例、无重复与置信区间，输出长度不同，不能拿两批样本的时延直接作加速结论。不含模型加载、文件持久化、评分；GPU峰值仅生成阶段，尚无完整请求峰值。

8项规则单测通过；独立产物6项核对通过，检查196行完整性、源码/gate/tokenizer/真实5GB权重哈希、下一层消费、下游变化、18份原始trace和精确消融对照。测试通过表明证据与实现吻合，不表示研究假设通过。

## 7. 限制、偏差与保留失败

1. **Codec部分实现：** 用属性值或UNKNOWN/AMBIGUOUS的短重复提示，在辅助forward提取assistant提示末token激活。source/depth/path保存在capsule，但未参与向量组合，未实现规格建议的完整字段token-span编码。
2. **动态值锚点：** 先从公开输入求capsule值，再用冻结算法生成含该值的辅助锚点。没有考官答案泄漏、目标prompt没有追加答案，也没有外部工具调用；但它是答案条件化的辅助推理，不是预存固定码本，更不证明模型自己发现了规则。额外成本已单列。
3. WRONG为固定错误值原型（marble/silver/tangerine），没有替换另一例的完整capsule；RECOVERY门控不匹配，均是当前实验设计欠缺，不宣称完全满足强因果协议。
4. 插入点是最后原prompt token，gate在查询行末token，二者不同。只测试无cache短结构化文本、贪心8token生成、小样本和单模型；不代表自然语言四领域、能力积累或权重固化。
5. BASE装有旁路观测hook，准确率对照可用，不能称完全卸载ONI的纯性能基线。
6. 包内DEV03、DEV08说明文字的hop计数与最近证据不一致；引擎按实际事实采用最近证据，不改原DEV题。
7. 首次标定进程曾exit1且未捕获诊断输出；未改代码重试成功。该事件不能追溯具体原因，不编造错误信息。成功driver日志保留；PowerShell对正常stderr进度/警告的NativeCommandError包装与实际进程退出码分开解释。
8. 全部正式错误答案、原始生成、capsule、门控和激活记录保留，无隐藏集调参。具体失败见考官 `failures.jsonl`、原始 `predictions.jsonl` 和 `score.json`。
