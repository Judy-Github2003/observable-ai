# 科学证据边界

- DMRV-01 比 GNJV/BMNV 多研究了一层：**在不同任务之间通过过去的奖励经验调整表征搜索策略**。策略表可查、可冻结，行动完全基于当前公开任务的诊断上下文和已有元训练反馈。
- 四种表示扩展操作、上下文桶、经验均值学习法、奖励函数都是 ChatGPT 提供的**开发者设计算法**。学生不能创造第 5 种动作；M 只能称为“在给定结构扩展集合中的策略性选择”。
- 元训练反馈为 **full-information counterfactual**：每个任务所有四种动作均被考官执行并评分；这是有监督的任务间策略学习，不是仅有一次试错反馈的在线 bandit。
- 元测试仍来自四个同类生成家族，只有变体、seed、训练/留出输入改变，不能称跨新世界规律或自然语言泛化。
- 在任务中获得的训练标签不等于元测试隐藏标签；学生的选择之前不能看到隐藏真值、目标表达式、家族名。
- 报告元训练全量搜索成本和部署选择成本；`candidateEvaluations` 是枚举候选数，不是 CPU 指令或真实 FLOPs；`wallMillis` 另计。
- `META_CONTEXT` 对 `GLOBAL_FEEDBACK` 才是本轮核心因果对照。还需检查 `SHUFFLED_CONTEXT`；如果仅胜无记忆的 `COLD_START`，不能把它归因于上下文学习机制。
- 无足够独立任务、置信区间或已建立的外部分布，此实验不能证明统计普适性。不能把多个 family 种子当成互相独立的真实自然任务。
- 不允许“总是宣称通过”：只有全部 16 个输入上的候选行为类唯一，学生才输出确定模型；若公开样本不足，必定存在弃答，单列 coverage 与 false-certainty。
- V 的哈希冻结和独立 Python 重算只证明程序内部数据一致；可见考官不证明研究者不可作弊。
- 不曾把 DMRV 与 B0 的能力注册、BMNV 概念文件、GNJV 的物理干预、SD-03 的局部修复集成为一个可持续学生。本包只能为未来组合提供隔离的研究证据。
- 阴性结果是科学成果，不是改代码刷绿的请求。
