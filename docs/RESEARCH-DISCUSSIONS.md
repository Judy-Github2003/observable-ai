## 2026-11-05 — A8 复核与 E3 架构意见

### 已验证事实（代码/测试可追溯）

- A8 初版整合器确实只用原始 observations 做预算诊断，没有把 A7 新增观察并入 after 状态；复核意见成立。
- `ProbeTrace` 已增加 `addedObservation`；整合器现在分开 beforeBudget / afterBudget，并输出 `ProbeStateChange`。
- A6 初版 `noConsistentCandidate = all consistentHashes.empty` 会把“因观察冲突跳过搜索”误判为“无一致候选”；已增加 `CandidateEvidenceState` 区分 NOT_RUN / RUN_WITH_ZERO_SURVIVORS / SEARCH_TRUNCATED / RUN_WITH_SURVIVORS。
- 当前全套测试 251/251（B0 173 + E3 78）；B0 生产源码未改动。

### 我的技术意见（独立，不等同于团队共识）

**1. 当前 E3 架构不足以支撑后续主动表征演化；最严重的是观测词汇固定。**

A4–A8 能做的仍是：在既有 `VisibleSchema` 和 B0 有界 IR 内，报告冲突、预算敏感、歧义，选择已有查询。它没有机制引入新的谓词、关系、时间上下文或新的观察通道。对 `x1 == x2 && y1 != y2`，只要没有新通道，任何只依赖现有 x 的确定性函数都无法区分；重复测量只能检验稳定性，不能创造可区分信息。当前 `LATENT_ALIASING` 只能证明“可见属性不能唯一决定标签”，不能证明系统能发现隐藏属性。

**2. A9 的关键不是“综合诊断得分更高”，而是降低虚假确定性。**

如果 A9 只比较最终准确率，A8 可能靠更多规则/更多查询获胜，却学不到何时不能说“已识别”。建议预注册：
- 主指标：在证据不足/冲突/预算截断世界上的 **false-certainty rate**（错误声称 IDENTIFIED / noise / representation gap）；
- 次指标：正确弃权率、探测后隐藏预测准确率、每单位成本的信息增益、证据轨迹完整率；
- 基线：A4-only、A5-only、A6-only、A7-only、A8，使用同一 observations、候选空间、预算和查询成本；
- 匹配对照：同一公开观察对应不同隐藏真值；打乱样本数量/顺序；A9 不得看到 family/oracle；
- 消融：去掉冲突、预算 facts、探测，分别看 false-certainty 与信息增益变化。

只有 A8 在“同预算、同查询成本、盲评”下降低 false certainty 且不显著损失有效辨识，才能说综合诊断有增量价值。

**3. 最可能失败的场景**

- 完全别名冲突（同 x 异 y）：无新传感器时不可解，系统应稳定输出 UNDETERMINED/冲突，而不是猜 hidden；
- 噪声与真实异质性不可分：缺少独立重复测量/来源可靠性模型；
- 非平稳/时变目标：当前无时间索引与漂移模型；
- 关系/层级/序列结构：当前只有扁平 Record；
- 搜索空间不匹配：A6 只能看到预算敏感，不能证明“表示不足”；
- 查询池无信息/高成本：A7 的 first-suggested 策略可能浪费预算；
- 来源伪造：sourceId/reliability 是自报字段，接口隔离不等于来源可信。

**4. 如果可改 E3-B/C，最想改的一点**

把“表示不足”的判定标准写死为可证伪协议，而不是由诊断器自由命名：
- 在固定 IR/预算下做可审计的穷尽或覆盖证明；
- 测试至少一个**新观察通道**（不是现有字段的新取值）；
- 若仍不可分，只能报告“在当前观测词汇与预算下不可辨识”，不得直接说世界缺少属性；
- 新谓词/关系必须经过 held-out 验证、压缩收益与跨任务迁移测试，才允许晋升。

E3-B 的核心应是“新通道的 cost/reliability/coverage 模型 + 价值信息选择”，E3-C 的核心应是“有类型约束的表示构造 + 独立验证 + 版本化/撤销”，而不是更深的 AST 搜索。

**5. 相对 ILP/程序合成/主动学习的差异化**

算法本身未必新颖；可能的差异化在**可审计的认识论契约**：
- 明确区分观察事实、当前假设、替代解释、适用范围与停止原因；
- 把“何时可以声称学会”变成可执行、可复核的状态机，而不是只报准确率；
- 表示修订带来源、版本、撤销和跨任务迁移证据；
- 允许 UNDETERMINED 并把它作为一等结果，而不是训练失败。

这需要实验证明：这种契约能降低 false certainty、提高跨任务迁移或降低再学习成本；否则只是术语包装。

### 待验证假设

- H1：在匹配世界/同预算下，A8 的 false-certainty 显著低于 A5/A6 单独。
- H2：A7 的区分性查询比随机/首个合法查询有更高信息增益/成本比。
- H3：仅靠重复测量不能区分噪声与稳定异质性；需要来源独立性模型。
- H4：E3-B 新通道的收益主要在完全别名冲突上，而非普通 SOLVABLE 世界。

### 被修正/推翻的早期说法

- “A8 已合并探测证据”在复核前不成立；现已修正。
- “无一致候选”不能由冲突未搜索推出；现已用 CandidateEvidenceState 修正。
- 不能把 LATENT_ALIASING 的碰撞解释为“隐藏属性已被发现”；仍只是不可辨识证据。
