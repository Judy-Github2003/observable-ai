证据标签：
- `[本机复跑]`：有指定环境/版本的实际复跑记录。
- `[开发者报告]`：由实现者或 DeepSeek 报告，未独立复现。
- `[有限]`：只在明确的有限词汇、预算或任务范围内成立。
- `[阴性结果]`：实验未支持假设，应保留。
- `[PROMISING]`：预注册或报告中的方向性信号，不等于独立证明。
- `[未知]`：当前没有足够材料作结论。

## 1. 早期项目定义（2026-10）
- 原始目标：显式知识、逻辑推理、自主研究循环、可选神经模型。
- 初始学生曾设想为 Kotlin 程序，教师为 DeepSeek，外部监督为 ChatGPT。
- 早期 V0/V1 重点是调用教师、保存答案和精确记忆复用；不能称为语义理解或通用学习。

## 2. V1 / V2 / B0
- V1：精确问题键 → SQLite 记忆 → miss 时调用教师；能够复用相同问题的答案，不等于语义学习。
- V2：在有限属性 schema 和有限假设空间内做规则枚举、主动询问、淘汰和晋升；不能外推为自主创造词汇。
- B0：Typed IR、类型检查、解释执行、SQLite 能力注册、不可变版本、依赖 pin、验证/激活门禁、撤销传播、有界能力组合、程序库学习基础。
- 2026-11-14 工程差距审计认为 B0/能力治理是可复用资产，但当前没有已证明的新谓词/新词汇发明机制；概念与能力需要分离。
