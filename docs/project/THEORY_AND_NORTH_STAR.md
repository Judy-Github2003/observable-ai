# Observable AI 理论与研究北极星

## 1. 原始研究意图

项目起点不是“给大模型外挂知识库”，也不是“从零预训练一个 LLM”。原始项目文件提出的方向是：显式知识、逻辑推理、自主研究循环及可选神经模型共同构成一个学习系统。

长期希望系统能够：
- 从字典、文献和其他原始资料中形成候选概念、词义、实体、关系和规则；
- 自己发现知识缺口、矛盾和未证实假设；
- 自己提出问题、查找资料并保留原文、来源、位置、时间和许可信息；
- 自己提出结论并验证，区分逻辑可证明、外部证据支持、未知和被反驳；
- 新知识进入时检查依赖旧知识的结论，并保留修订历史；
- 总结成功与失败，改进下一轮学习和研究策略。

核心认识论原则：概率模型可以负责语义解析、候选生成和搜索排序；显式规则负责形式推导；证据系统负责现实事实核查。模型自信、向量相似度或教师重复确认都不能单独作为真值依据。

## 2. Observable 的含义

“可观测”不是单纯把日志写出来。系统应能追溯：
- 结论来自什么原始输入；
- 哪些是观察事实，哪些是模型候选，哪些是推导；
- 使用了哪些规则、程序、工具和模型版本；
- 哪个反例导致了修订；
- 新知识依赖哪些旧知识；
- 旧知识撤销后哪些结论需要失效或重新验证；
- 某项能力是否由教师/模型直接提供，还是由系统自身经验形成。

## 3. 学习层级（研究分析框架，不是已达成等级）

2026-11-14 理论审计将“自主表征形成”拆成四级：

- L1 表达搜索：在给定原语、类型和预算内搜索一致表达式。
- L2 抽象发明：从成功结构中抽出新的可复用结构/谓词/模板。
- L3 本体修订：新增/合并/拆分类型、关系、观察通道或身份规则。
- L4 学习策略改进：改变提出假设、选择实验、分配预算的策略本身。

该审计认为当时现有系统的强项是认识论工具与实验治理；现有能力主要落在有限 L1；L2 曾尝试但结果阴性；L3 未实现；L4 只有受限迹象。此结论是 2026-11-14 的历史审计，不应直接等同于 2026-11-16 最新路线。

## 4. 当前研究重点的更新

项目负责人 2026-11-16 最新决定：先扎实验证系统本身能否学习四大基础能力：
- 逻辑
- 数学
- 代码
- 语义

这不是否定 L2/L3/L4，而是把当前可行性路线调整为：先用现有 MiniCPM 和临时 Agent 工具，构造能在四个领域持续学习的 Observable AI 原型，再逐步研究自主产生新能力和学习机制。

## 5. 什么才算“系统学会”

不能把下列情况单独算作学习：
- MiniCPM 一次回答正确；
- 把答案存入数据库；
- 对完全相同的问题做精确查表；
- 只在训练题或开发题上提高；
- JUnit 测试通过；
- 代码变多或模型调用次数增加。

最低限度的学习证据应包含：
1. 明确的学习前基线；
2. 可追溯的新知识/规则/程序/策略；
3. 学习过程中的证据、错误和修订；
4. 学习后在未见任务或未见组合上的表现；
5. 与同一模型零历史基线比较；
6. 与普通历史记录/检索基线比较；
7. 排除题目泄漏、标签泄漏、教师直接完成和评测器泄漏；
8. 能够复现并报告失败。

## 6. 四领域共同学习循环（目标设计）

获取材料/样例
→ 识别已有知识与缺口
→ 形成候选概念、规则、公式、程序或策略
→ 选择实验
→ 独立验证
→ 记录证据与来源
→ 更新知识/技能/策略版本
→ 在未见任务上迁移评测
→ 失败时诊断并决定下一步学习。

四领域可以共用循环，但验证器不同：
- 语义：定义、原文证据、关系约束、反例、范围和歧义；
- 逻辑：形式推导、模型检查、反例、UNKNOWN；
- 数学：精确计算、符号检查、证明或反例；
- 代码：类型检查、编译、单元测试、性质测试、沙箱执行。

## 7. 开放问题

- 如何区分模型预训练知识与系统后天学得的知识？
- 如何让新概念/谓词进入词汇而不是只在旧词汇内搜索？
- 如何避免把“唯一候选”误判为真实规律？
- 如何让学习策略本身成为可版本化、可评估的学习对象？
- 如何测量知识压缩、程序复用、跨任务迁移与教师依赖率？
- 多编码是否有真正互补信息，而不是把相关编码误称为正交？
- 如何把概念（认知对象）与能力（可执行行为）分开？
