## 真实 DeepSeek 教师实验

以下各行都启动独立的 Kotlin/JVM 进程，使用同一个 SQLite 数据库。计时包含 JVM、数据库和必要的 Agent 启动开销：

| 操作 | 教师 Agent 调用次数 | 结果来源 | 整次耗时 |
| --- | --- | --- | --- |
| 首次问“什么是苹果？” | 1 | DeepSeek 教师原始回复，保存为未核验 | 5.097 秒 |
| 新进程再问同一问题 | 0 | 本地记忆，回复逐字符一致 | 0.340 秒 |
| `--no-teacher` 再问同一问题 | 0 | 本地记忆，回复逐字符一致 | 0.327 秒 |
| `--no-teacher` 问“什么是香蕉？” | 0 | `unknown / teacher_disabled` | 0.327 秒 |

四次实验合计一次教师 Agent 调用。后续命中并不启动 DSH 适配器，关闭教师时也不创建任何教师后端。未获得教师内部模型调用次数或费用，不能据此给出模型调用/成本数字。实验中没有把香蕉写入真实记忆。

已存苹果记录：

- 数据库：`runs/memory.db`，schema_version=1。
- 状态：`unverified`；kind=`raw_teacher_answer`；匹配规则=`identity-v1`。
- 初始 run_id：`6153e876-5494-4e85-bc7d-a61af696d7f6`。
- 教师 session_id：`session-6a99bbcb-c3ae-4fb6-b9cd-9d9c3b3e0df9`。
- 命中记录中保存相同的初始来源，不将复用说成新教师回答。

执行证据：`runs/v1-live-events.jsonl`、`runs/v1-live-results.json`。实际 CLI 的 `--forget` 路径也已用单独的 mock 数据库验证：保存 → 撤销 → 关闭教师后返回未知，没有撤销真实苹果记忆。

## 能力归属与边界

相比 V0，这次获得了本地持久记忆、精确查询、来源追溯和未命中处理；已存问题可以在教师缺席时复用。没有证明语言理解、概念抽象、分类推理、事实真伪判断或自主改进学习方法。教师回复仍未核验，复用可能重复教师原答案中的错误。

回退可使用 `--student v0`；撤销单条记录使用 `--forget`。教师工具和隔离边界沿用 V0，本次不运行教师生成的候选代码。
