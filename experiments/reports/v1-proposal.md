# 第一项能力升级：V0 → V1 精确记忆复用

日期：2026-11-04。研究者已明确要求开始第一步简单学习。

观察：V0 对同一个苹果问题连续两次调用教师。V0 的真实基线见 `v0-demo.md`。

来源：研究者提出升级目标；Codex向 DeepSeek Harness 提供项目背景和候选方案；DeepSeek返回五条建议；Codex实现并进行客观测试。教师原始意见和提交背景保存于 `v1-teacher-advice.md`，关联会话 ID 可从 `runs/v1-teacher-advice-events.jsonl` 查看。本次不属于学生自主发现学习需求。

改动：加入一个 SQLite 问答记录表；同一个原始问题精确命中即可复用；miss 才请求教师并保存原始回复。保留 `--student v0`，默认运行 V1。教师关闭时，命中仍返回，miss 明确返回 `unknown`，不隐式求助。支持撤销记录。mock 使用单独数据库。

采用的教师意见：保留原始问题、匹配键、来源、原始运行与教师会话；明确 `unverified/revoked` 状态；schema_version；答案与来源在一次事务中写入；区分命中、miss、调用和未知；跨进程与关闭教师验证。

最小化选择：匹配规则固定为 `identity-v1`，不 trim、不变换大小写、不做 NFC、不替换全半角或换行。问题原文与匹配键此时相同；文字稍有变化即 miss。暂不为单一原始回复再存一份相同答案副本。称为“外部指导下获得记忆复用能力”，不声称形成概念、学会推理或自主发明学习方法。

对照与验收：V0 重复问题仍两次求助；V1 首次求助、后续新进程精确命中零次求助；关闭教师后仍能答已存问题、新词返回未知；香蕉不能误返回苹果；撤销后不再命中；来源与未核验标记可追踪。

回退：使用 `--student v0`，它不会读写 V1 记忆；单条错误记录用 `--forget` 撤销。数据库和运行日志位于被忽略的 `runs/`，本轮不修改用户现有 DSH 会话或全局配置。
