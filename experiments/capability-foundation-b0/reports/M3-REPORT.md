## 结果摘要

- **设备世界**：`power == usb AND port == c`，4 组公开样本下筛选唯一，验证通过并激活；未见留出样本 2/2 一致。
- **访问世界**：`role == admin AND level == 3`，同一套 IR 原语、空能力库重新组合并激活。
- **退化**：撤销 `core.is_red` 后，依赖它的目标从可组合退化为 `no_consistent_candidate`。
- **拒绝**：证据不足返回 `ambiguous` 与区分性查询；3 变量多数函数超出 `maxDepth=3` 返回 `refused`。
- **未验证拒绝**：候选写入后未经验证无法激活或执行。

## 语义与归因

1. **候选空间**由开发者定义（`not/and/or/eq/call` + 有界深度）；具体候选由搜索与证据筛选产生，登记来源为 `student_composed`。
2. 搜索、筛选、验证、激活严格分阶段；搜索不能写 `verified`，验证不能跳过套件，激活不能跳过验证。
3. **等价只在公开查询域上判定**（`bounded_equivalence`），不是全局语义等价证明。
4. **留出集不参与学习**：只传给事后 `HeldOutEvaluator`，组合/筛选接口不接收。
5. 没有教师调用（`teacher_calls=0`，离线运行）；这不代表“脱离教师”，只表示本轮实验无教师参与。
